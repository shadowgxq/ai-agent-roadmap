# 个人记账本产品需求文档

> 产品名称：轻记账  
> 文档版本：V1.0  
> 文档状态：草案  
> 更新日期：2026-07-28  
> 需求来源：工作流验证用业务需求  
> 需求评审：未评审

## 1. 产品背景

用户在日常消费后，往往只需要快速记录金额和用途，并在月底回答三个问题：钱花在了哪里、是否接近预算、当月还剩多少钱。功能繁重的财务工具通常需要维护账户、资产和复杂分类，增加了日常记账成本。

轻记账面向个人用户，提供低门槛的收支记录、月度预算和分类统计能力。产品强调快速完成一笔记录，并保证账单、预算和统计使用一致的数据口径。

## 2. 产品目标

### 2.1 目标

- 用户可以在一次连续操作中完成一笔收入或支出记录。
- 用户可以按月份查看账单明细，清楚了解当月收入、支出和结余。
- 用户可以设置当月支出预算，并及时了解预算使用状态。
- 用户可以通过分类统计判断主要支出去向。
- 用户修改或删除账单后，各页面的汇总结果保持一致。

### 2.2 成功标准

- 首次使用的用户无需阅读说明即可找到记账入口并完成记录。
- 任意一笔账单完成新增、编辑或删除后，账单、预算和统计中的金额同步更新。
- 用户可以明确区分正常、接近预算和达到预算上限三种状态。
- 无数据、筛选无结果或保存失败时，用户能够理解当前状态并继续操作。

## 3. 目标用户与场景

### 3.1 目标用户

希望简单记录个人日常收支，但不需要专业资产管理能力的个人用户。用户通常每天记账数次，并在消费后、周末或月底查看支出情况。

### 3.2 核心场景

1. 用户消费后立即记录金额、分类和日期。
2. 用户发现账单金额或分类有误，返回修改或删除该记录。
3. 用户查看本月账单，筛选某类支出并核对明细。
4. 用户设置月度预算，随时查看剩余额度和风险状态。
5. 用户在月底查看分类占比，了解主要支出去向。

## 4. 产品范围

### 4.1 本期范围

- 收入和支出记录的新增、编辑与删除。
- 月度账单汇总、明细浏览和条件筛选。
- 当月支出预算的设置、修改和使用进度。
- 月度收支汇总及支出分类统计。
- 账单和预算数据在同一设备上的持续保留。

### 4.2 非本期范围

- 账号注册、登录、云同步和跨设备使用。
- 多账本、多人共享和家庭协作。
- 银行卡、现金等资产账户管理。
- 自定义分类、周期记账和自动记账。
- 账单导入、导出和票据识别。
- 多币种、汇率换算、借贷和报销管理。
- 支付能力、消息推送和社交分享。

## 5. 信息架构

产品采用移动端优先布局。底部导航包含“账单”“预算”“统计”三个主入口；“记一笔”为从账单页进入的全屏操作页，不占用底部导航入口。

| 页面   | 页面目的                   | 主要入口                     |
| ------ | -------------------------- | ---------------------------- |
| 账单   | 查看月度汇总和账单明细     | 默认首页、底部导航           |
| 记一笔 | 新增、编辑或删除一笔账单   | 账单页记账按钮、点击账单记录 |
| 预算   | 查看并管理当月支出预算     | 底部导航                     |
| 统计   | 查看月度收支和支出分类分布 | 底部导航                     |

删除确认、筛选和预算设置采用弹窗或抽屉承载，不形成新的独立页面。

## 6. 功能需求

### 6.1 账单页

#### 6.1.1 月度汇总

- 页面默认展示当前月份。
- 用户可以切换到已有账单的历史月份，也可以返回当前月份。
- 不允许切换到晚于当前月份的月份。
- 汇总区域展示所选月份的收入、支出和结余。
- 结余等于所选月份收入总额减去支出总额，允许为负数。
- 汇总金额始终统计所选月份的全部账单，不受明细筛选条件影响。

#### 6.1.2 账单列表

- 账单按交易日期倒序分组展示，最近日期位于最上方。
- 同一天内，后创建的账单优先展示。
- 每条账单展示分类、可选备注和金额；收入与支出需要有明确的视觉差异。
- 日期分组展示当日收入和支出小计。
- 点击一条账单进入“记一笔”页面的编辑状态。
- 页面提供始终可发现的记账按钮，点击后进入新增状态。

#### 6.1.3 筛选

- 用户可以按收支类型筛选：全部、收入或支出。
- 用户可以在已选择收支类型后进一步按对应分类筛选。
- 切换收支类型时，清除与新类型不匹配的分类条件。
- 页面清楚展示当前生效的筛选条件，并支持一键重置。
- 筛选仅影响账单列表和日期小计，不改变页面顶部的月度汇总。

#### 6.1.4 页面状态

- 首次使用且没有任何账单时，展示引导记第一笔账的空状态。
- 所选历史月份没有账单时，展示该月份无账单的空状态。
- 筛选后没有匹配结果时，保留筛选条件并提供重置入口。
- 数据读取失败时，展示错误原因概述和重试入口，不展示可能过期的汇总结果。

### 6.2 记一笔页面

#### 6.2.1 新增账单

- 页面提供“支出”和“收入”类型切换，默认选择支出。
- 用户需要填写金额、分类和交易日期，可以填写备注。
- 交易日期默认使用当前日期。
- 分类不默认选中，用户必须主动选择。
- 保存成功后返回账单页，并展示保存成功反馈。
- 返回账单页时定位到该账单所属月份；若账单日期为当前月份，则保持当前月份。

#### 6.2.2 编辑账单

- 编辑状态预填原账单的类型、金额、分类、日期和备注。
- 用户修改任意字段并保存后，覆盖原账单，不生成重复记录。
- 从收入切换为支出或从支出切换为收入时，原分类被清空，用户需要重新选择。
- 用户修改交易日期导致账单归属月份变化后，原月份和新月份的汇总、预算及统计都需要更新。

#### 6.2.3 删除账单

- 只有编辑状态提供删除入口。
- 删除前必须二次确认，并明确告知删除后无法在产品内恢复。
- 用户取消确认时，账单及当前编辑内容保持不变。
- 删除成功后返回账单页，并同步更新相关月份的汇总、预算和统计。

#### 6.2.4 表单规则与反馈

- 金额为必填项，必须大于 `0`，最多保留两位小数。
- 单笔金额不得超过 `9,999,999.99` 元。
- 分类为必填项，只能从当前收支类型对应的固定分类中选择。
- 交易日期为必填项，不得晚于当前日期。
- 备注为选填项，去除首尾空格后不得超过 50 个字符。
- 校验失败时，在对应字段附近说明原因，并保留用户已填写的其他内容。
- 保存期间不允许重复提交。
- 保存失败时停留在当前页面，保留全部输入并提供再次保存的机会。
- 用户修改内容后直接返回，需要确认是否放弃未保存的更改。

### 6.3 预算页

#### 6.3.1 预算设置

- 预算页只管理当前自然月的支出预算。
- 未设置预算时，展示本月累计支出，并提供“设置预算”入口。
- 用户可以设置或修改当月预算金额。
- 预算金额必须大于 `0`，最多保留两位小数，且不得超过 `9,999,999.99` 元。
- 修改预算不改变既有账单，只重新计算预算使用状态。
- 新自然月开始后不自动沿用上月预算，用户需要为新月份重新设置。

#### 6.3.2 预算进度

- 已使用金额等于当前月份全部支出账单的金额之和，收入不计入预算使用。
- 剩余金额等于预算金额减去已使用金额；发生超支时同时展示超出金额。
- 页面展示预算金额、已使用金额、剩余或超出金额，以及直观的使用进度。
- 使用比例低于 80% 时显示正常状态。
- 使用比例达到 80% 且低于 100% 时显示接近预算提醒。
- 使用比例达到或超过 100% 时显示达到预算上限的风险状态；超过 100% 时明确显示超出金额。
- 新增、编辑或删除当前月份的支出后，预算进度立即按最新数据重新计算。

#### 6.3.3 页面状态

- 当前月份没有支出时，已使用金额显示为 `0`，预算仍可正常设置和修改。
- 预算保存失败时，保留用户输入和原预算，提示失败并允许重试。
- 数据读取失败时，不展示未经确认的预算进度，并提供重试入口。

### 6.4 统计页

#### 6.4.1 月度收支统计

- 默认展示当前月份，支持切换到已有账单的历史月份。
- 不允许切换到晚于当前月份的月份。
- 展示所选月份的收入总额、支出总额和结余，计算口径与账单页一致。
- 月份切换后，所有统计内容同步更新。

#### 6.4.2 支出分类统计

- 仅对所选月份的支出账单进行分类统计，收入不参与分类占比。
- 使用图表展示各支出分类的金额占比，同时以列表展示分类金额和占比。
- 分类列表按支出金额从高到低排列。
- 占比等于分类支出金额除以当月支出总额，展示到一位小数。
- 图表和列表使用一致的分类颜色及金额口径。

#### 6.4.3 页面状态

- 所选月份没有任何账单时，展示无统计数据的空状态。
- 所选月份只有收入、没有支出时，保留收支汇总，并在支出分类区域说明暂无支出数据。
- 数据读取失败时，展示错误状态和重试入口，不使用旧月份数据替代当前月份。

## 7. 业务规则

### 7.1 收支分类

支出分类固定为：餐饮、交通、购物、居住、娱乐、医疗、其他。

收入分类固定为：工资、奖金、理财、其他。

本期不支持新增、重命名、排序或删除分类。两个类型中的“其他”视为不同分类。

### 7.2 金额与月份归属

- 产品币种固定为人民币，所有金额以元展示。
- 月度收入是该自然月全部收入账单金额之和。
- 月度支出是该自然月全部支出账单金额之和。
- 月度结余等于月度收入减去月度支出。
- 账单按交易日期归属自然月，而不是按创建时间或最后修改时间归属。
- 汇总和统计计算使用账单的完整金额，界面展示时统一保留两位小数。

### 7.3 数据一致性

- 同一笔账单在账单页、预算页和统计页中使用相同的类型、金额、分类和日期。
- 新增、编辑或删除成功后，所有受影响页面在用户下次查看时必须呈现最新结果。
- 保存失败或删除失败时，不得部分更新汇总、预算或统计。
- 页面刷新或重新打开产品后，已成功保存的账单和预算继续保留。

### 7.4 时间规则

- “当前日期”和“当前月份”以用户设备本地日期为准。
- 产品不接受未来日期的账单。
- 自然月从每月 1 日开始，到该月最后一天结束。

## 8. 核心用户路径

### 8.1 首次记录支出

1. 用户进入账单页，看到首次记账空状态。
2. 用户点击记账入口。
3. 用户保持“支出”类型，填写金额，选择分类并确认日期。
4. 用户保存账单。
5. 产品返回账单页，新账单出现在对应日期下，月度支出和结余同步更新。

### 8.2 修改错误账单

1. 用户在账单列表中点击目标账单。
2. 产品打开编辑状态并展示原始内容。
3. 用户修改金额或分类并保存。
4. 产品返回账单页，原记录被更新，相关汇总、预算和统计按新内容计算。

### 8.3 管理月度预算

1. 用户进入预算页。
2. 用户设置当前月份预算并保存。
3. 产品根据本月已有支出展示使用进度和剩余额度。
4. 用户继续新增支出后再次进入预算页，看到最新进度及对应风险状态。

### 8.4 查看支出去向

1. 用户进入统计页并选择目标月份。
2. 产品展示该月收支汇总和支出分类分布。
3. 用户通过图表和排行识别支出金额最高的分类。

## 9. 通用交互与状态要求

- 金额、日期和汇总结果需要清晰区分，重要金额不得被截断或与操作按钮重叠。
- 执行保存、删除和预算修改时，操作按钮需要提供进行中状态并阻止重复操作。
- 成功反馈简短明确；失败反馈说明当前结果未生效，并提供可执行的下一步。
- 空状态需要解释当前为何无内容，并在适用时提供记账、重置筛选或设置预算入口。
- 删除等不可恢复操作必须使用确认流程，普通保存不增加额外确认步骤。
- 用户切换月份、筛选条件或底部导航时，页面结构保持稳定，避免内容加载导致主要操作入口跳动。

## 10. 验收标准

### 10.1 记账与账单

1. 首次进入产品且无账单时，账单页展示首次记账空状态，用户可以从该状态进入记一笔页面。
2. 用户新增一笔当日 `35.50` 元的餐饮支出后，账单列表展示该记录，当月支出增加 `35.50` 元，结余相应减少。
3. 用户新增一笔工资收入后，该金额计入当月收入和结余，但不计入预算已使用金额。
4. 金额为空、等于 `0`、小于 `0`、超过两位小数或超过单笔上限时，产品阻止保存并指出金额问题。
5. 用户选择未来日期时，产品阻止保存并说明交易日期不能晚于当前日期。
6. 用户把支出记录切换为收入时，原支出分类被清空；重新选择收入分类并保存后，各项汇总按收入计算。
7. 用户将一笔账单的日期从当前月改为上月后，该记录从当前月移至上月，两个自然月的汇总和统计均按新日期更新。
8. 用户确认删除账单后，该记录不再展示，相关月度汇总、预算和统计同步更新；取消删除则不产生任何变化。
9. 用户在存在未保存更改时返回，产品要求确认是否放弃；选择继续编辑后，已填内容保持不变。
10. 用户刷新页面或重新打开产品后，之前成功保存的账单仍然存在。

### 10.2 浏览与筛选

1. 用户切换月份后，账单列表和顶部月度汇总展示目标月份的数据。
2. 用户筛选“支出”和“交通”后，列表只展示目标月份的交通支出，顶部月度汇总仍展示该月份的全部收支。
3. 用户从支出筛选切换到收入筛选时，已选的支出分类被清除。
4. 筛选无匹配记录时，产品展示筛选无结果状态；重置后恢复该月全部账单。
5. 同一日期存在多条账单时，后创建的记录显示在前；不同日期的记录按日期倒序分组。

### 10.3 预算

1. 当前月未设置预算时，预算页展示本月累计支出和设置预算入口，不显示虚构的剩余额度。
2. 当预算为 `1,000.00` 元、当月支出为 `799.99` 元时，预算显示正常状态。
3. 当预算为 `1,000.00` 元、当月支出达到 `800.00` 元但低于 `1,000.00` 元时，预算显示接近预算提醒。
4. 当预算为 `1,000.00` 元、当月支出达到或超过 `1,000.00` 元时，预算显示达到预算上限的风险状态；超过时同时展示超出金额。
5. 用户编辑或删除本月支出后，预算已使用金额、比例和状态按最新支出重新计算。
6. 新月份开始后，产品不自动复制上月预算，新月份显示未设置预算状态。

### 10.4 统计与异常恢复

1. 统计页的月度收入、支出和结余与账单页相同月份的汇总完全一致。
2. 某月存在多个支出分类时，分类列表按金额从高到低排列，金额之和等于该月支出总额。
3. 某月只有收入时，统计页保留正确的收支汇总，支出分类区域展示暂无支出数据。
4. 某月没有任何账单时，统计页展示无统计数据状态，不展示占比图表。
5. 保存账单或预算失败时，用户输入得到保留，账单汇总、预算和统计不发生部分更新，用户可以重试。
6. 数据读取失败时，对应页面展示错误状态和重试入口，不把其他月份或旧数据冒充为当前结果。

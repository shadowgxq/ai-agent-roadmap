# W21｜Agent 评估与交付：E2E、Langfuse 与部署

> **目标**：通过可复现的 Agent Eval、故障归因与观测数据，证明 W20 业务闭环的质量，并交付可运行的演示项目。
> **投入**：建议累计 12–18h，按验收推进。**前置**：W20 业务、安全、恢复与前端闭环通过。
> **方式**：深入学习 Agent 的非确定性评估、证据与成本取舍；Docker、CI、README 等常规交付工程直接复用已有经验。

## 1. 核心要掌握

- **Eval 分层**：W18 关注 single / multi-agent 的效果与开销；W19 的 retrieval eval 衡量召回、引用；本阶段新增面向完整工单业务的 E2E Eval，不能拿最终回答流畅度替代可靠性。
- **客观断言优先**：分类、工具权限、审批、引用 ID、状态迁移和副作用用确定性断言；自由文本质量才使用 LLM-as-judge 并抽样人工审核。
- **可观测与归因**：按 `run_id`、`thread_id`、`ticket_id` 将 Graph、LLM、检索、工具、审批 trace 关联；报告成功率、token、费用、延迟、重试和失败类别，所有日志先脱敏。
- **优化要有基线**：每次只改变一个变量，报告质量、成本、延迟和安全的影响，不因单次成功就认定改进。

## 3. 落地执行

### Session 1：冻结 30 条 E2E 评估集
- 8 条分类/澄清、8 条检索/引用/无答案、5 条低风险回复、4 条高风险审批、3 条恢复/幂等、2 条跨租户/注入。
- 固定知识库、模型/工具预算和业务 fixture；每次评估隔离 checkpoint、run/event 和工具副作用。
- **完成标志**：每条用例有预期结果、证据和失败分类，可以独立重跑。

### Session 2：实现自动化评估报告
- 一条命令运行完整用例，输出成功率、citation correctness、工具/审批违例、平均成本、p50/p95 延迟与失败类别。
- 复用 W19 的 50 条检索评估及 W18 的对照结果，分别展示，不把不同口径混成同一个总分。
- **完成标志**：失败能定位到 retrieval、grounding、approval、tool、infra、security 等具体环节。

### Session 3：Langfuse Trace 与证据关联
- 打通 Graph node、LLM、retrieval、tool、approval 及最终结果的 trace/span/score。
- 按 `run_id` 关联持久业务事件，保留模型成本与延迟；日志、trace、SSE 不暴露 token、cookie 或完整 PII。
- **完成标志**：任一失败用例可找到对应脱敏 Trace，确认失败发生在哪一步。

### Session 4：故障与安全回归
- 复跑 W20 的 20 并发与 15 条安全用例；补充 DB/Redis/Worker 故障、LLM 超时和恶意 MCP 输出的恢复检查。
- 确保无永久 queued、越权访问、重复副作用与“断流即成功”的错误判断。
- **完成标志**：失败可复现，恢复边界可解释；不把已有安全用例重新包装成新任务。

### Session 5：质量 / 成本优化
- 在固定 baseline 上逐次调整 retrieval top-k、prompt、router 或重试策略，记录质量、费用和延迟变化。
- 至少保留 2 个有数据支持的改进和 1 个效果不佳的反例；没有证据不增加 reranker 或新 Agent。
- **完成标志**：Eval 数据可以复核架构取舍，而非只展示主观观感。

### Session 6：部署与展示证据
- 使用 Docker Compose 启动已有 React、API、Worker、PostgreSQL、Redis，补 migration、健康检查和启动说明；公开 Demo 只使用模拟 CRM 与低权限数据。
- README 汇总架构、关键契约、安全边界、Eval 结果、成本与延迟、演示方式；准备 15 分钟项目口述与技能矩阵。
- **完成标志**：干净环境可按运行手册复现部署，并演示「创建工单 → 引用 → 审批 → 工具 → 审计」。

## 6. 常见坑速查

- 只看最终答案成功率：会掩盖检索、审批、恢复或越权缺陷；分层报告。
- 让 LLM judge 判断是否执行过工具：应检查真实工具与审计事件。
- 用 Langfuse 当状态存储：它负责观测，业务真相仍在 PostgreSQL。
- 测试复用上次 checkpoint：会导致伪成功；按 case 隔离状态和 fixture。
- 为展示部署生产数据或任意 Shell：公开 Demo 只暴露模拟工具和受限数据。
